# Portfólio — Checkpoint 6

Portfólio pessoal de Hiago Silva de Oliveira, feito com HTML, CSS e JavaScript.

## Estrutura

- `index.html`: conteúdo e seções da página.
- `css/style.css`: estilos responsivos e identidade visual.
- `src/main.js`: conteúdo dos projetos, experiência, contatos e interações.
- `index.html`: lista de habilidades e demais seções estáticas.
- `img/`: imagens dos projetos e da seção visual da hero.
- `promptsErefs.txt`: prompts e referências que já estavam registrados.
- `PROCESSO_CP6.md`: análise das referências, decisões visuais, prompts e correções conforme o PDF do Checkpoint 6.
- `img/references/`: capturas visuais usadas como referência para o processo.

## Abrir localmente

Abra `index.html` em um navegador ou use uma extensão de servidor local para testar a página e seus links.

## Antes da entrega

Complete em `PROCESSO_CP6.md` os links públicos do repositório e do deploy final. Inclua também uma reflexão pessoal e os eventos que quiser apresentar.
